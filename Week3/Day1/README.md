# Day 1 - Supervised Learning Fundamentals

## Overview
Today I learned the fundamentals of supervised learning and how machine learning models are trained using labeled datasets. I explored the difference between regression and classification problems and became familiar with the Scikit-learn workflow.

## What I Learned
- Introduction to supervised learning.
- Difference between regression and classification.
- Features (`X`) and target (`y`).
- The Scikit-learn workflow:
  - Create a model
  - Train the model
  - Make predictions
  - Evaluate performance
- Splitting datasets into training and testing sets.
- Why evaluating on unseen data is important.

## Practical Work
- Loaded a dataset using Pandas.
- Split the dataset into features and target.
- Performed an 80/20 train-test split using `train_test_split`.
- Verified the shapes of the training and testing datasets.
- Documented why the test set should never be used during training.
