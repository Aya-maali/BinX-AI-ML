# Week 3 - Supervised Learning with Scikit-learn

## Overview

During this week, I learned the fundamentals of supervised machine learning using Scikit-learn. I explored both regression and classification problems, trained multiple machine learning models, evaluated their performance using appropriate metrics, and completed an end-to-end supervised learning project following a complete machine learning workflow.

## Topics Covered

- Supervised Learning Fundamentals
- Regression vs Classification
- Scikit-learn API
- Train/Test Split
- Linear Regression
- Logistic Regression
- Classification Metrics
- Confusion Matrix
- Decision Trees
- Random Forests
- Support Vector Machines (SVM)
- k-Nearest Neighbors (k-NN)
- Model Comparison
- Feature Importance
- Data Preprocessing
- Feature Scaling
- One-Hot Encoding
- Preventing Data Leakage
- End-to-End Machine Learning Pipeline

## Practical Work

Throughout the week, I completed several hands-on exercises and notebooks, including:

- Preparing datasets by separating features and target variables.
- Splitting datasets into training and testing sets.
- Training Linear Regression models for continuous value prediction.
- Evaluating regression models using MAE, RMSE, and R².
- Building Logistic Regression classifiers.
- Evaluating classification models using Accuracy, Precision, Recall, F1-Score, Confusion Matrix, and AUC-ROC.
- Training and comparing Decision Tree, Random Forest, SVM, and k-NN models.
- Analyzing feature importance using Random Forest.
- Applying preprocessing techniques such as feature scaling and categorical encoding.
- Building a complete supervised learning pipeline from data exploration to final evaluation.

## Skills Gained

- Understanding supervised learning concepts.
- Building regression and classification models.
- Working with the Scikit-learn API.
- Selecting appropriate evaluation metrics.
- Comparing multiple machine learning models.
- Implementing preprocessing techniques correctly.
- Preventing data leakage during model development.
- Documenting machine learning workflows using Jupyter Notebook.
