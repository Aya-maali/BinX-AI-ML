# Day 2 - Linear Regression

## Overview
Today I built my first regression model using Scikit-learn. I learned how linear regression predicts continuous values and how to evaluate the model using common regression metrics.

## What I Learned
- Linear Regression fundamentals.
- Model training and prediction.
- Model coefficients and intercept.
- Regression evaluation metrics:
  - MAE
  - RMSE
  - R² Score
- Comparing model performance against a baseline.

## Practical Work
- Trained a Linear Regression model.
- Generated predictions on the test dataset.
- Analyzed feature coefficients.
- Evaluated the model using MAE, RMSE, and R².
- Compared the model with a baseline prediction.
