# Day 2 — Cross-Validation

Today, I learned how **K-Fold Cross-Validation** provides a more reliable evaluation than using a single validation split.

I applied **5-Fold Cross-Validation** using `cross_val_score` and calculated the **mean and standard deviation** of the results to understand the model's average performance and stability.

I also used **Stratified K-Fold** for the classification problem and compared different KNN values to select the best model based on cross-validation performance.
