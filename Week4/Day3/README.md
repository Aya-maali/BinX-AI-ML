# Day 3 — Bias-Variance & Diagnosing Model Fit

Today, I focused on understanding **underfitting, overfitting, and the bias-variance trade-off**. I learned how model complexity affects performance and how to use the **train-validation gap** to diagnose model fit.

For the practical part, I used a **Decision Tree Classifier** to intentionally create an overfitted and an underfitted model. I compared their training and validation scores, then reduced the tree complexity to improve the overfitted model.

I also explored **Ridge and Lasso regularization** and learned how regularization can help control model complexity and reduce overfitting.

By the end of the day, I was able to identify model fit problems and apply different techniques to improve generalization.
