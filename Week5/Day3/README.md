Day 3 — Dimensionality Reduction with PCA

I learned about Dimensionality Reduction and why datasets with many features can become difficult to work with and visualize. I studied PCA (Principal Component Analysis) and how it creates new components that keep the most important variance from the original data.

I practiced scaling the data before applying PCA, checking the explained variance ratio, and using cumulative explained variance to decide how many components to keep. I also used PCA to reduce high-dimensional data to 2D for visualization and learned the trade-off between reducing dimensions and losing some of the interpretability of the original features.

Main Takeaway

These two days helped me understand how to find hidden patterns in data and simplify complex datasets. I learned how to choose a suitable clustering method based on the data structure and how PCA can reduce many features while preserving most of the important information.
