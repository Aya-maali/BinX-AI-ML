# Day 4 - Exploratory Data Analysis (EDA) Part 1

## Overview

Today I learned the fundamentals of Exploratory Data Analysis (EDA) and why it is an essential step before building machine learning models. I explored a real-world dataset using Seaborn and practiced analyzing both numerical and categorical variables.

## Topics Covered

- Introduction to Exploratory Data Analysis (EDA)
- Statistical visualization with Seaborn
- Univariate analysis
- Histograms
- Box plots
- Count plots
- KDE plots
- Outlier detection using the IQR method

## Hands-On Practice

Using the Titanic dataset, I completed the following tasks:

- Loaded and explored the dataset
- Generated histograms for all numerical variables
- Created box plots to visually detect outliers
- Applied the IQR method to identify outliers in the Fare column
- Generated count plots for categorical variables
- Documented observations and insights using Markdown cells

## Key Takeaways

- EDA helps understand the structure and quality of data before modeling.
- Histograms reveal the distribution of numerical variables.
- Box plots make it easy to identify potential outliers.
- The IQR method provides a systematic way to detect unusual values.
- Count plots are useful for exploring categorical data and identifying class imbalance.
- Clear visualizations and documented observations are important parts of the data analysis process.
