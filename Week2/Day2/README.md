## Key Concepts

- Probability measures the likelihood of an event.
- Probability values range from **0 to 1**.
- Bayes' Theorem updates probabilities using new evidence.
- The Normal Distribution follows a bell-shaped curve.
- The Binomial Distribution models repeated success/failure experiments.
- The Uniform Distribution gives every outcome an equal chance.
