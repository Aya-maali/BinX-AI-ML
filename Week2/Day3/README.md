# Day 3 - Linear Algebra for Machine Learning

## What I Learned Today

Today I started learning the basics of **Linear Algebra**, which is one of the core foundations of Machine Learning.

First, I learned why Linear Algebra is called the language of Machine Learning and how machine learning models represent data using vectors and matrices instead of regular tables.

Then, I practiced creating **vectors** with NumPy to represent a single data sample and learned how to check their dimensions using the `shape` attribute.

After that, I worked with **matrices** to represent multiple data samples, explored rows and columns, and learned how to access different parts of a matrix.

Next, I learned about the **Dot Product** and how it is used to calculate predictions by multiplying feature values with their corresponding weights. I implemented this calculation both manually and using NumPy's `np.dot()` function.

I also practiced **Matrix Multiplication** using the `@` operator to generate predictions for multiple samples at the same time.

Finally, I intentionally created a **shape mismatch error** during matrix multiplication, read the error message, understood why it happened, and fixed it by using compatible matrix dimensions.

## Practical Tasks Completed
