# Day 5 — EDA Part 2: Correlation & Data Storytelling

## Overview
In this day, I continued learning Exploratory Data Analysis (EDA) by focusing on understanding relationships between variables and how to communicate insights from data.

I learned how to perform **bivariate analysis**, calculate and visualize **correlations**, use **pair plots** to discover patterns, and build a complete EDA notebook with clear explanations and storytelling.

---

## Learning Objectives
During this day, I learned how to:

- Analyze relationships between two variables.
- Create scatter plots and grouped box plots.
- Calculate and interpret correlation between numerical features.
- Visualize correlations using heatmaps.
- Understand the difference between correlation and causation.
- Use pair plots to quickly explore relationships in a dataset.
- Create a complete EDA notebook with a clear data story.
